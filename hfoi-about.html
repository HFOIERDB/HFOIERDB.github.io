📋 数据来源

✨ 功能特性

  • 选手搜索 — 按姓名、学校、拼音检索
  • 选手详情 — 比赛记录、评级、评分（每场贡献与总分）
  • 学校排名 — 按团体奖和个人奖数量排序
  • 比赛纵览 — 查看每场比赛的获奖分布

📊 评级规则（0-10 级）

评级取该选手所有比赛中最高的那一档，只看比赛名次和奖项，不分省内外。同一名选手升级到不同学校，记录仍合并算 max。

级别对应成绩（从低到高）
0 级无记录
1 级市赛小学组 三等奖
2 级市赛小学组 二等奖 / 初中组 三等奖 / CSP-J 三等奖
3 级市赛小学组 一等奖 / 初中组 二等奖 / CSP-J 二等奖 / CSP-S 三等奖
4 级市赛小学组 rank≤20 / 初中组 一等奖 / CSP-J 一等奖 / CSP-S 二等奖 / NOIP 三等奖
5 级市赛初中组 rank≤20 / CSP-J rank≤20 / CSP-S 一等奖 / NOIP 二等奖
6 级CSP-S rank≤20 / NOIP 一等奖
7 级NOIP rank≤20 + 一等奖 / APIO 铜牌 / WC 铜牌
8 级NOI 铜牌 / 省选 B/E 队 / APIO 银牌 / WC 银牌 /
9 级NOI 银牌 / APIO 金牌 / WC 金牌 / 省选 A 队
10 级NOI 金牌

特殊：贾治辰 直接 9 级（同人特批）。同一比赛名次越靠前级别越高；rank ≤ 20 算前 20 特档。
